# 3D models

**Status: APPROVED (partial).** glTF triangle meshes with base-color textures
and the first node animation are loaded and rendered behind the 2D scene.

## Loading

- Stage DEFs read `[Model] model = <file.gltf>` relative to the stage directory.
- Storyboard DEFs read `[SceneDef] model = <file.gltf>` relative to the
  storyboard directory.
- `gltf::import` resolves the document, `.bin` buffers, and data URIs.

## Rendering

- Every triangle primitive in `mode = TRIANGLES` contributes vertices with
  `baseColorFactor`, `TEXCOORD_0`, and `NORMAL` (default +Y).
- `baseColorTexture` images are decoded to RGBA and uploaded per material;
  primitives without a texture use a white 1x1 fallback.
- Normal maps perturb the transformed vertex normal (tangentless approximation,
  `normalTexture.scale` supported).
- `occlusionTexture`/`metallicRoughnessTexture` supply per-vertex occlusion,
  roughness (G), and metallic (B), multiplied by the material factors.
- `emissiveTexture * emissiveFactor` is added after shading.
- Lighting is computed per vertex before upload using a metallic-roughness
  Cook-Torrance BRDF: GGX/Trowbridge-Reitz normal distribution, Smith-Schlick
  geometry, Schlick Fresnel (dielectric F0 0.04 blended toward base color by
  metallic), and energy-conserving diffuse. A fixed view `+Z` and a light rig
  drive the direct term. The default is a white key `(0.3, 0.8, 0.5)` at
  intensity 1.0 plus a cool fill `(-0.45, 0.25, -0.6)` at 0.35.

  Content can configure up to eight lights with stage
  `[Model] lightN = dirx,diry,dirz, r,g,b, intensity` or storyboard
  `[SceneDef] modellightN = ...`; four-value form
  `dirx,diry,dirz,intensity` uses white. Configured lights replace the default
  rig, and each contributes its own GGX specular and diffuse term.
- Envmap ambient uses a split-sum approximation: diffuse samples the base
  equirectangular level, specular samples a roughness-selected level along the
  reflection vector, and a `32x32` CPU BRDF LUT supplies the `(scale, bias)`
  split-sum terms. Levels 1–4 are generated by GGX importance sampling (64
  samples per texel) at increasing roughness, so the mip chain is
  GGX-convolved rather than box-filtered. The BRDF LUT is a CPU table sampled
  per vertex, not a GPU texture.
- The final fragment is `texture(baseColor, uv) * shadedColor`.
- `[Model] envmap` (stage) or `[SceneDef] envmap` (storyboard) loads an
  equirectangular PNG/image as image-based ambient. Each vertex samples the
  map along its world normal (a one-sample diffuse irradiance approximation)
  instead of the analytic hemisphere; prefiltered/roughness-aware IBL is not
  modeled.
- The mesh bounding box is centered horizontally, scaled so its largest axis
  spans 70% of the 240px screen height, and placed standing at 88% screen
  height.
- Vertices are baked into 320x240 screen space with depth `0.98`, drawn with a
  dedicated wgpu triangle pipeline before sprite/font quads. Depth testing
  keeps the 2D scene in front.
- Loading a new stage/storyboard replaces the active model; a missing or
  invalid file logs a warning and leaves no model.

## Not modeled

- All glTF animation clips are loaded. `[Model] anim = name|index` (stage) or
  `[SceneDef] modelanim = name|index` (storyboard) selects the active clip;
  clip 0 is the default. Translation/rotation/scale and morph-weight channels
  are sampled (step/linear) through the node hierarchy each frame. Animation
  time follows the match clock (or storyboard scene clock) in seconds.
- Skinning: `JOINTS_0`/`WEIGHTS_0` and `inverseBindMatrices` deform vertices
  with up to four weighted joints per vertex, driven by the animated node
  hierarchy.
- Morph targets: `TARGET_POSITION` deltas are blended by node/mesh default
  weights or by the first clip's `weights` channel.

- GPU BRDF LUT textures.
- `ModifyBGCtrl3D` also targets 3D model nodes: `ctrlid` is the glTF node index
  (`-1` = all nodes), and `value = z[, xscale[, yscale]]` scales the node's
  baked screen extent around the model center and offsets its depth. Animation
  still drives the node TRS; the controller only adds the render override.
- 3D placement/offset/rotation/scale fields from the stage/storyboard DEF.
