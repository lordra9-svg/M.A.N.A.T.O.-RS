# Bundled content

This directory contains original content created for M.A.N.A.T.O.-RS.

## Characters

`chars/kaen`, `chars/nival`, and `chars/ordan` are original characters by the
M.A.N.A.T.O.-RS contributors. Their DEF/CNS/CMD/AIR/SFF/SND files and the
minimal `common.cns` state file are licensed under the MIT license in
[`LICENSE`](LICENSE).

The sound banks (`*.snd`) are original synthesized effects generated by
[`../tools/gen_sfx.py`](../tools/gen_sfx.py).

## Training Stage

`stages/training` is the Training Stage by **Gacel**, licensed under
**CC BY 3.0**. See [`stages/training/ATTRIBUTION.md`](stages/training/ATTRIBUTION.md).

## No stock content

No M.U.G.E.N stock characters, stages, sprites, sounds, or state files are
included here. The bundled `common.cns` is an original minimal implementation,
not a copy of Elecbyte's `common1.cns`.
